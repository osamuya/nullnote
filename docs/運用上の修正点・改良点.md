# 運用上の修正点・改良点

## 修正点

- [#005] Claude codeなど別のソフトで修正すると、コンフリクトが起きます。これを何とか解決したい。

## 終了
- [#002] #、##などのタイトルの上部はプレヴューでもう少しmarginを取る。その他のブロックも同じかもしれない。リスト、テーブルなどのブロック要素の上部にmarginがほしい。 
- [#001] `インラインブロック`のデザイン修正。編集画面はこのままで問題ないが、 プレビュー側のデザインを変更。
	- `ライトモード`は、黒文字、グレー背景、1pxか2pxの角丸。薄いクレーの枠線。
	- `ダークモード`は、白文字、グレー背景（背景のグレーより薄いグレー）、1pxか2pxの角丸。 薄い白の枠線。
- [#003] 入力速度問題
- [#006] [command + F]で検索窓を出したときに、カーソルのポインターが自動的に検索窓にいくようにする。（現在は、編集画面の選択行） 検索窓を閉じたら元の編集画面の箇所にポインターが戻るようにする。
- [#004] プレビューボタンを押したときに、編集画面が一瞬消えて、ちょっと時間をおくと再表示されます。おそらく再読み込みされているのではないかという予想ですが、この一瞬消えてしまうところを直して、常に表示させたままにしたい。
