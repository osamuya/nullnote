## Nullnote ver 1.1

[Nullnote v1.1 Download](https://sabanote.com/apps/)

マイナーアップデートですが、いくつかの機能追加と不安定な機能の安定化をはかりました。利用中の小さな不具合の修正といくつかの便利機能を追加しています。

### 改行すると、行頭の印が続く

- リストの`-` 番号の`1.` 引用の`>`は、改行すると次の行にも自動的に入ります。
- インデントの深さもそのまま保ちます。表の行も、区切りを揃えた次の行（テーブルのレコード行）を自動的に用意します。

### 閉じる側が自動で入る

- コードフェンス```` ``` ````、強調 `**`、リンク`[]()`、インラインコード``` `` ```は、開いたときに閉じる側も入ります。
URL を貼るとリンクの形に整えます。
- またそれぞれショートカットも追加しています。

### Windowタブが使いやすくなった

- タブが1枚のときもタブバーを出すようにしました。窓を結合する取っ手が常にあります。タブを別の窓に分けたときも、その窓にタブバーが出ます。
- ⌘N は前面の窓のタブとして、Finder から開いた .md は別の窓として開きます。

### ファイルの場所を、開ける・写せる

- 上部のファイル名を右クリックすると、そのファイルのあるフォルダを Finder で開けます。
- 本文の右クリックとファイルメニューに「パスをコピー」`⌥⌘C`、「フォルダのパスをコピー」、「ファイル名をコピー」を足しました。

### 外から書き換えられたときの合流を修正

- AIなどが同じファイルを直したとき、ぶつかった箇所に印が出ないタイミングがありました。突き合わせの基準をディスクから取るようにして、印が確実に出るようにしています。
- 印はプレビューでも印として出ます。これまでは Markdown として読まれてしまい、直前の段落が見出しに化けることがありました。

### 見た目の修正

- 行末で折り返したインラインコードが、文字の無い余白まで塗っていたのを直しました。
